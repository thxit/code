# A股量化交易系统 - 启动说明

## 问题解决

已修复数据获取问题，新增了多个数据源支持：
- **新浪财经** - 备用行情数据源
- **东方财富** - 备用行情数据源  
- **AKShare** - 主数据源

## 启动步骤

### 方法一：使用批处理文件（推荐）
1. 打开文件资源管理器，导航到 `d:\code\jiaoyixitong`
2. 双击运行 `start.bat`
3. 保持命令提示符窗口打开
4. 打开浏览器访问：http://127.0.0.1:5000

### 方法二：命令行启动
```cmd
cd d:\code\jiaoyixitong
venv\Scripts\activate.bat
python webapp/app_simple.py
```

## 功能说明

系统包含以下功能模块：

1. **大盘趋势分析** - 分析上证指数走势和技术指标
2. **板块轮动** - 分析各行业板块表现
3. **情绪热点** - 涨停股票和市场情绪分析
4. **资金流向** - 北向资金和行业资金流动
5. **选股功能** - 多种策略选股
6. **交易信号** - 开仓/清仓建议

## 数据源配置

数据获取模块已增强，支持多个数据源自动切换：
- 主数据源：AKShare
- 备用数据源：东方财富API
- 备用数据源：新浪财经API

当主数据源失败时，系统会自动尝试备用数据源，确保数据获取的可靠性。

## 注意事项

1. 首次启动可能需要较长时间（约10-30秒）进行数据初始化
2. 请确保网络连接正常
3. 如果数据显示为空，请等待几分钟后刷新页面
4. 服务器运行时请保持命令提示符窗口打开
