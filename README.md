# code

个人 AI 编程项目集合，包含多个独立子项目。

## 子项目一览

| 目录 | 说明 |
|------|------|
| `jiaoyixitong/` | 交易系统：A股选股、回测、指标计算与行情分析（Python） |
| `mdwriter/` | Markdown 写作工具（Electron） |
| `snake/` | Snake 量化系统（Electron + quant_system） |
| `tts-app/` | 文本转语音应用（Electron） |
| `twitter_scraper.py` | Twitter 抓取脚本（twint） |

## 说明

- 各子项目的依赖与构建产物（`node_modules/`、`venv/`、`dist/` 等）已通过 `.gitignore` 排除，仓库只保留源代码。
- 部分子项目内有各自的 `README.md`，可查看具体用法。
